# QuestLife website surface

## Purpose

The website is a small, public companion to the QuestLife mobile app. It hosts
trust-building pages and secure account handoffs; it is not the admin product.

## Audience and primary task

QuestLife members arrive here from an account email. The page should reassure
them that their action worked, then return them to the mobile app with one
clear next step.

## Brand direction

- Playful, adventurous, encouraging.
- Warm paper background, lively blue primary action, and small colorful
  accents from the mobile app.
- GeistPixel for display moments and Rubik for readable body copy.
- Tactile, rounded app-like surfaces and buttons; never reuse the admin
  dashboard visual system.

## Accessibility and safety

- Target WCAG AA contrast, keyboard focus, responsive text, and a useful
  no-JavaScript/error state where possible.
- Auth handoff URLs are never displayed or logged. One-time codes are removed
  from browser history immediately after the app link is prepared.
- Auth pages must not be indexed.
